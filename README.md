1. basics-1.py illustrates a simple decision process, where a1 = 10, if a1 > 100, then output is 11. if a1 < 100, then output is 10. This describes only two outputs exist, either 10 or 11, depends on whether a1 > 100 or not. The second example is a repeated decision process, where a1 = 10, if a1 < 50, a given condition, then a1 will conduct a math calculation. if a1 > 50, output is more than 50. 
2. project-1.py illustrates a simple skincare recommendation system, where x = "to brighten skin", if x = "to brighten skin", then output is the matching ingredients. if skin concern x is others, such as "to reduce wrinkles" or "to moisturize skin", then output are different recommendations. 
3. project-1 basic skincare recommendation system.py creates a skincare recommendation system for customers. When a customer typed in her name, age, and skincare goal, he/she will see the recommended ingredient(s).This system is intended to solve skincare questions coming from the users. The input is users' concerns like "to brighten skin", coming from users, and the system finally gives out what ingredient will help users to solve their skincare concern. This system assumes users know what they want to improve on their skin. However, it couldn't solve when users type more than one concern at one time. In the future, it needs to integret models like LLM to better give out skincare recommendations. 
4. project-2 basic skincare ingredients explanation.py create a simple function by which users can type in any of the four ingredients to get a simple explanation. This system is to solve the situations when users don't know the function of an ingredient. The input is common skincare ingredients, coming from common knowledge. The system finally gives out the decision to help users learn what the ingredients they types are for, and the system assumes Capitalized first letter and users know the name of skincare ingredients. It cannot solve ingredients beyond the ingredients set in def() function. In the future, we need to insert more data into the def() function to make it better.
